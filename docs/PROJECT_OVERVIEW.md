# Project vision

Jade Desktop is an independent, local-first AI companion project. It explores a friendly character-driven desktop experience built on maintainable architecture and clear security boundaries.

## Goals

- Reliable local language-model conversation.
- A readable, elegant desktop HUD and expressive Jade character.
- Owner-controlled, explicitly scoped access to private knowledge and future services.
- Modular components with Windows-first development and future Linux validation.
- A professional engineering portfolio that records tests, trade-offs, and learning.

## Planned experience

The envisioned interface includes chat, character presentation, system status, an agenda, and optional audio. Email, calendar, and personal-note integrations are future permission-sensitive capabilities, **not current features**.

## Current focus

The Windows development desktop has been demonstrated. The active security milestone is validating authenticated desktop/backend communication and Windows service identity isolation. Real private memory remains disabled.
