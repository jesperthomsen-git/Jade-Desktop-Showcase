# Visual direction

Jade's intended aesthetic combines a calm, readable dark desktop interface with restrained mint/jade-green and violet accents.

## Character concept

Long silver-white hair with a side braid, violet eyes, a floral silver hair ornament with jade-green details, a dark high-collar outfit, and a light jacket.

**The official concept portrait is not the rigged Live2D model.** Avatar integration is planned for a later milestone.

## Interface priorities

- Readable chat first.
- Elegant character presentation without clutter.
- Useful system, agenda, and command panels.
- Clear disabled/authorized/experimental states.
- Accessible contrast and typography.

Reviewed concept art and screenshots can be published later; raw desktop screenshots must be checked for private data first.
